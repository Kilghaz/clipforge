# UX audit backlog, September 2026

Findings from the component spec cards (`docs/ux/components/*.md`, written
2026-09-24 from the Fluent, Spectrum, Primer and NN/G pages) that are
**feature-sized**: they need view-model or core work, not a component fix,
and are therefore not closed by the component pass. Each maps to an area of
`/ux-feature-audit`, which will re-judge the whole task before fixing.

Component-level gaps from the same cards were fixed on 2026-09-24 (see the
"Resolution" section at the bottom of each card).
